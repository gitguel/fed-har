## Convenção

Uma apresentação = **um PDF + um `.md` com o mesmo nome**. O `.md` descreve o que
está no deck, o contexto e o escopo; o PDF é o registro do que foi apresentado.
Se a apresentação tiver assets soltos (figuras, tabelas, planilhas), eles vão numa
subpasta com o mesmo nome.

**Deck entregue é registro imutável** — não se regera nem se edita depois. Versão
nova é arquivo novo.
